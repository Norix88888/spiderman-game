# SPIDER-VERSE :: 웹 스윙

브라우저에서 바로 도는 3D 스파이더맨 게임. 외부 에셋 0개 — 도시·슈트·거미줄·범인 전부 코드로 생성.

**▶ 플레이: https://norix88888.github.io/spiderman-game/**

## 게임플레이

도시에 범죄 현장 4곳이 상시 발생한다. 빨간 광선 기둥과 미니맵을 보고 날아가서 거미줄로 범인을 포박한다.

| 범인 | 행동 | 필요한 거미줄 |
|---|---|---|
| 도둑 | 도망친다 | 2발 |
| 깡패 | 달려들어 주먹질 | 3발 |
| 총잡이 | 거리를 두고 사격 | 3발 |

다 맞히면 하얀 코쿤으로 포박되어 체포된다. 연속 체포는 콤보 배수, 현장 전원 체포 시 보너스.
맞으면 체력이 깎이고 0이 되면 기절 후 리스폰.

## 조작

**PC**

| 키 | 동작 |
|---|---|
| 마우스 | 시점 |
| WASD | 이동 · 스윙 중 W=줄 당김(가속), S=줄 풀기, A·D=조향 |
| 좌클릭 (홀드) | 거미줄 스윙 — 앞 빌딩을 자동으로 찾아 부착 |
| 우클릭 | 조준한 범인 포박 / 범인이 없으면 그 지점으로 웹 짚 이동 |
| Space | 점프 · 벽차기 |
| Shift | 질주 / 공중 다이브 |
| Tab, 1~8 | 슈트 변경 |
| R · G · P | 리스폰 · 그래픽 품질 · 일시정지 |

벽에 부딪히면 자동으로 붙고, WASD로 기어오른다.

**모바일** — 왼쪽 화면 드래그=이동(끝까지 밀면 질주), 오른쪽 화면 스와이프=시점, `웹` 홀드=스윙, `포박`=거미줄 발사. 가로 모드 권장.

## 구현 메모

- **도시** `src/city.js` — 블록을 로트로 분할해 세그먼트 적층형 빌딩 360여 동 생성. 창문은 알베도+발광맵 타일을 벽 크기에 맞춰 UV 스케일링해서 건물이 커져도 창문 크기가 일정하다. 지오메트리를 전부 머지해 드로우콜 10여 개. 충돌은 메시가 아니라 AABB + 52m 공간격자(레이캐스트 포함)로 처리.
- **거미줄** `src/web.js` — 직선이 아니라 장력에 따라 처지는 현수선을 계산하고, 평행수송 프레임으로 트위스트 없는 원형 단면 튜브를 매 프레임 생성한다. 손 쪽은 가늘고 부착점 쪽은 굵으며 실 꼬임 굴곡까지 들어간다. 부착점엔 방사줄+나선고리로 그린 둥근 거미줄 자국이 남았다 사라진다.
- **슈트** `src/suits.js` — 8종. 캔버스에 진짜 거미줄 패턴(방사줄 + 안쪽으로 처진 나선)을 그려 텍스처화하고, 파트별로 primary/secondary/accent를 매핑해 클래식의 빨강상의-파랑하의 같은 배색을 재현. 아이언 스파이더는 기계팔 4개, 그웬은 후드, 느와르는 발광 고글.
- **캐릭터** `src/character.js` — 애니메이션 파일 없이 관절 계층 + 절차적 포즈(달리기/공중/스윙/다이브/벽크롤/3점 착지). 눈 렌즈는 평면 Shape를 구면에 투영.
- **물리** `src/player.js` — 스윙은 진자 구속(로프 길이 초과 시 위치 보정 + 반경방향 속도 제거). 최저점에서 놓으면 접선 속도가 남아 가장 멀리 날아간다.
- **범죄** `src/crime.js` — 현장 생성, 3종 AI(도주/돌진/사격), 웹샷 조준 판정, 포박·체포.

## 로컬 실행

```
node server.js     # http://localhost:5180
```

`index.html`을 더블클릭해도 된다 (three.js를 `vendor/`에 넣어둬서 인터넷 없이도 동작).
